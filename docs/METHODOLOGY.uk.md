# Методологія

Як знімки цього репозиторію збираються з відкритого реєстру МВС.

## 1. Джерело

| Поле | Значення |
|---|---|
| **Набір** | Відомості про транспортні засоби та їх власників |
| **Розпорядник** | Міністерство внутрішніх справ України |
| **Портал** | https://data.gov.ua/dataset/06779371-308f-42d7-895e-5a39833375f0 |
| **Ліцензія** | CC BY 4.0 |
| **Роки** | 2013–2026 |

Точні файли — id ресурсу, назва файлу, SHA-256 і кількість рядків за кожен період — у
[SOURCES.uk.md](SOURCES.uk.md).

## 2. Одна ревізія на період

Розпорядник перезаписує файл поточного року на місці і за роки публікував кілька часткових і
накопичувальних файлів. Змішування ревізій дає ту саму подію двічі, щойно розпорядник змінює
написання поля між ревізіями (номер кирилицею чи латиницею, кузов, заповнений пізніше,
переформульована назва операції). Тому кожен період береться рівно з **одного** файлу джерела,
і періоди не перекриваються (див. SOURCES.uk.md).

## 3. Обробка

1. **Читання.** CSV з роздільником `;`, UTF-8, усі значення як текст. Колонки зіставляються за
   назвою без урахування регістру; три розкладки джерела (19 колонок у 2013–2020, 20 колонок з
   `VIN` у 2021 – 2026-04-29, 17 колонок з 2026-04-30 зі склеєною колонкою операції) зводяться до одної.
2. **Порожні значення.** Порожні рядки й текст `NULL`/`None` стають NULL. Інші значення, зокрема
   заглушки джерела (`НЕВИЗНАЧЕНИЙ`, рік `1900`), лишаються.
3. **Дати.** `d_reg` розбирається з `YYYY-MM-DD`, `DD.MM.YYYY` або `DD.MM.YY` у `DATE`.
4. **Числа.** `oper_code`, `make_year`, `capacity`, `own_weight`, `total_weight` беруться як цілі;
   нецілі значення стають NULL. `power_kwt` приймає десяткову кому або крапку. Значення не
   виправляються і не масштабуються.
5. **Ідентифікатор.** `record_id` = MD5 обрізаних полів джерела (без назви операції, бо джерело
   формулює одну операцію по-різному).
6. **Дублікати.** Рядки з однаковим `record_id` — однакові в усіх полях джерела — публікуються
   один раз. Нечіткого зіставлення немає.
7. **Нормалізація категорій** публічними довідниками:
   * марка → латиницею, написання каталогу для марок, що є в каталозі;
   * модель → модель довідкового каталогу, побудованого як марка → модель → покоління.
     Варіант, який каталог вважає поколінням, публікується під своєю моделлю
     (`GOLF PLUS` → `Golf`, `C4 PICASSO` → `C4`). Якщо модель каталогу залежить від року
     випуску, вирішує рік (`MEGANE SCENIC` 1996–1998 → `Megane`, пізніше → `Scenic`).
     Зіставлення за моделлю джерела з пробілами й дефісами і без них; моделі, якої немає
     в каталозі, — модель джерела латиницею;
   * паливо → основне + додаткове (`ЕЛЕКТРО АБО ДИЗЕЛЬНЕ ПАЛИВО` → `Дизель` + `Електро`);
   * кузов → група кузова; колір `ПОМАРАНЧЕВИЙ (ОРАНЖЕВИЙ)` → `ОРАНЖЕВИЙ`;
   * назва операції: латинська `I` всередині кириличних слів → кирилична `І`.
   Кожен довідник має рівно один запис на значення джерела.
8. **Похідні поля.** `payload` = `total_weight − own_weight` (NULL, якщо від'ємне); нормалізація
   `vin` і `is_valid_vin`; транслітерація номера й `is_valid_plate` — див.
   [schema.uk.md](../schema/schema.uk.md).
9. **Потужність за VIN.** `power_kwt` переноситься на інші рядки того самого валідного VIN у
   джерелі. Зовнішні дані не використовуються.

## 4. Що не публікується

* Номерні знаки за 2013–2020.
* Будь-що, чого немає у файлах джерела: публікуються лише значення з файлів МВС.

## 5. Результат

| Властивість | Значення |
|---|---|
| **Формати** | Parquet (Snappy) і CSV (UTF-8, `,`) |
| **Файли** | `mvs_opendata_YYYY_MM.{parquet,csv}` (місяць), `mvs_opendata_YYYY.{parquet,csv}` (рік) |
| **Де** | GitHub Releases `vYYYY.MM` і `vYYYY.full`; Zenodo |

Місячний файл містить реєстрації з `d_reg` у цьому календарному місяці, з першого по останній день.

## 6. Перевірка

Для кожного періоду опубліковані рядки звірено з файлом джерела: MD5 кожного рядка джерела
пораховано незалежно від опублікованого, і опублікована множина дорівнює множині унікальних
рядків джерела — жодного пропущеного, жодного зайвого. Числа за періодами — у
[DATA_QUALITY_REPORT.uk.md](DATA_QUALITY_REPORT.uk.md).
